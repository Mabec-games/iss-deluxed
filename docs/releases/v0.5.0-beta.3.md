# ISSD Native v0.5.0-beta.3

Touch-control beta for Windows x64, Linux x64 and Android 8.0+. Supply your own
supported retail USA cartridge dump; ROMs, personal configuration and saves are
not included.

## Changes

- Clear native **A/B/X/Y** labels replace misleading fixed action names.
- Eight-direction thumb movement replaces the old nine-cell grid, with a smaller
  circular dead zone, visible diagonal arrows and an active-sector highlight.
- The movement finger stays captured until release, even when sliding beyond the
  drawn pad. SDL finger-array reorder cannot interrupt movement when an action
  finger lifts; multiple touch devices are distinguished.
- A moving thumb indicator shows direction and returns to centre on release.
  Hiding/disabling, layout changes and suspension clear held input. Rotation waits
  for all fingers to lift before accepting input against the new layout.
- Retain both tactical cameras, replay edge-player history, campaign card fixes,
  audio timing, shootout/substitution/campaign fixes and independent stadiums.
- Include Mod Studio and the MEADOW/HARBOR example pack in platform bundles, plus
  separate editor/example and Liga MX/World Cup 2026 packs.

## Installation

Windows: extract the ZIP and run `ISSDNative.exe`; keep SDL2 and the deny list
beside it. The frozen Mod Studio executable is included. Linux: extract the
tar.gz and run `./ISSDNative`; requires system SDL2 and compatible x86-64 libraries
(tested on Ubuntu 24.04). Bundles include editor Python/Pillow/Tcl/Tk source.
Android: install the APK (arm64-v8a and x86_64, minimum Android 8), upgrade code
**9**, retaining the previous beta's development signing certificate.
`SHA256SUMS.txt` covers the eight binary/package assets.

## Validation

Fresh complete regression: **456 tests and 8 subtests passed, 6 skipped**, with
no failures. One system-Python Tcl/Tk editor check was skipped in that run and
passed independently afterward; the other five are existing opt-in/fixture
exclusions. Windows/Linux/Android builds, real SDL overlay rendering, clean
package/editor acceptance and APK upgrade/signature checks passed.
See [release validation](../RELEASE_VALIDATION_0_5_0_BETA_3.md) for details.
No physical Android device was connected: automated input behavior and APK build
checks do not certify thumb feel, touch latency or Android gameplay/lifecycle.
Physical four-controller and full human campaign acceptance remain 1.0 work.
No untested macOS or separate SteamOS binary is published.
